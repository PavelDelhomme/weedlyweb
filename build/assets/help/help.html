Guide d'utilisation et raccourcis clavier

⌨️ Raccourcis clavier

Navigation générale

  • Ouvrir un nouvel onglet Ctrl + T
  • Fermer l'onglet actuel Ctrl + W
  • Dupliquer l'onglet actuel Ctrl + Shift + D
  • Focus sur la barre d'URL Ctrl + E
  • Afficher/masquer la palette de commandes Ctrl + Shift + C
  • Afficher cette page d'aide Ctrl + H

Favoris

  • Ajouter la page actuelle aux favoris Ctrl + D

Navigation web

  • Recharger la page F5
  • Aller à la page d'accueil Bouton Accueil

🎯 Fonctionnalités principales

Gestion des onglets

  • Création et fermeture d'onglets multiples
  • Groupes d'onglets pour organiser votre navigation
  • Défilement horizontal des onglets avec la molette de la souris
  • Chaque onglet a sa propre session de navigation indépendante

Gestion des favoris

  • Ajout rapide de favoris avec Ctrl + D
  • Barre de favoris accessible sous la barre d'URL
  • Gestionnaire de favoris complet avec organisation par groupes
  • Clic droit sur les favoris pour plus d'options

Palette de commandes

🎨 Palette de commandes (Ctrl + Shift + C)

La palette de commandes vous permet d'accéder rapidement à des fonctionnalités avancées :

  • /cve - Analyser les CVE (Common Vulnerabilities and Exposures) sur la page actuelle
  • /request - Envoyer des requêtes HTTP personnalisées
  • /analyze - Afficher l'analyseur de requêtes réseau
  • /history - Afficher l'historique de navigation
  • /clear cache - Vider le cache du navigateur

Astuce : Utilisez Échap ou Ctrl + Shift + C pour fermer la palette de commandes.

🔧 Menu contextuel

  • Clic droit sur les favoris pour modifier ou supprimer
  • Menu hamburger (☰) en haut à droite pour accéder aux paramètres et options

💡 Conseils et astuces

  • La barre d'URL accepte les URLs complètes ou des termes de recherche
  • Les onglets peuvent être organisés en groupes pour une meilleure productivité
  • L'indicateur de chargement (spinner) dans la barre d'URL vous informe du statut de chargement
  • Le bouton étoile (☆/*) indique si la page actuelle est dans vos favoris
  • Tous vos favoris et paramètres sont sauvegardés automatiquement
