# Raccourcis clavier — WeedlyWeb (GTK)

Les raccourcis fonctionnent **même lorsque le focus est dans la page web** (WebKit), grâce à un intercepteur global GTK.

## Navigation et onglets

| Raccourci | Action |
|-----------|--------|
| `Ctrl+T` | Nouvel onglet |
| `Ctrl++` / `Ctrl+pavé+` | Nouvel onglet (AZERTY : souvent `Ctrl+Shift+=`) |
| `Ctrl+W` | Fermer l'onglet actif |
| `Ctrl+Shift+W` | Fermer l'onglet actif (idem) |
| `Ctrl+Shift+D` | Dupliquer l'onglet actif |
| Clic molette sur onglet | Fermer l'onglet (sauf onglet épinglé) |

Si le dernier onglet est fermé, l'application se ferme.

## Favoris et pages

| Raccourci | Action |
|-----------|--------|
| `Ctrl+D` | Ajouter aux favoris (popover) |
| `Ctrl+L` / `Ctrl+E` | Focus barre d'URL |
| `Ctrl+R` / `F5` | Actualiser la page |
| `Ctrl+H` | Aide |

## Interface

| Raccourci | Action |
|-----------|--------|
| `F11` | Plein écran sur **le moniteur où se trouve la fenêtre** (pas tout le bureau virtuel) |
| `Ctrl+Shift+C` | Palette de commandes |

## Barre d'URL

| Bouton | Action |
|--------|--------|
| Étoile | Ajouter / retirer des favoris |
| ◐ | Mode sombre des pages (type Dark Reader) |
| ≡ | Mode lecture (texte épuré) |

## Menu contextuel onglet (clic droit)

- Fermer / Dupliquer
- Renommer l'onglet / Reprendre le titre de la page
- Épingler / Désépingler
- Ajouter aux favoris — ou Modifier / Supprimer si déjà en favoris
- Déplacer vers un groupe d'onglets
