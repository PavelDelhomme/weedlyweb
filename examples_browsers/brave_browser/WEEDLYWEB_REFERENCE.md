
# Note WeedlyWeb

Le dépôt [brave/brave-browser](https://github.com/brave/brave-browser) sert surtout issues/releases/wiki.
Le code UI Chromium est dans [brave/brave-core](https://github.com/brave/brave-core).

Objectifs de recréation dans WeedlyWeb (inspirés Brave) :
- Groupes d’onglets colorés, switch, ouvrir/fermer groupe
- Favoris dossiers + overflow … + gestionnaire
- Menu hamburger : Nouvel onglet / fenêtre / privée / Tor, Historique (split), Mots de passe, Outils développeur
- Split buttons (action + alternatives)
